# Тренажер ШК РТУ МИРЭА

Статический мобильный сайт с вопросами по разделам:

- История
- Внеучебка
- Администрация
- Документация
- Общее

## Быстрый запуск

Откройте `index.html` в браузере.

## Публикация на GitHub Pages

1. Загрузите в репозиторий файлы `index.html`, `styles.css`, `app.js` и папку `assets`.
2. В настройках репозитория откройте Pages.
3. Выберите ветку `main` и папку `/root`.
4. Сохраните настройки и дождитесь ссылки GitHub Pages.

Сайт не требует базы данных, сервера и сборки.
